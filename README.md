# Gender bias in academia: sources and data

Resources for a data-driven talk on gender bias in academia.

- `SOURCES.md`: the annotated source list (126 sources, 10 sections).
- `sources.csv`: the same list as a table (`scripts/parse_sources.py` builds it).
- `gender-bias-data/`: one folder per section and source ID, holding the downloaded PDF, data, figures and notes; `manifest.csv` records the status of each source.
